# Skills

SKILL.md files for Claude and other agentic tools, oriented to theological reading and to keeping a note vault. Point your agent at a skill's `SKILL.md` and ask it to set the method up for your notes.

- [`witness/`](witness/): keep a dated record of what you meet or remember, linked to the thing's own note.
- [`ots-notes/`](ots-notes/): create and edit single notes in an Ontological Type System vault.
- [`quill/`](quill/): an essay-writing companion, from first spark to publication handoff.
- [`nuance-finder/`](nuance-finder/)
- [`sermon-to-small-group-guide/`](sermon-to-small-group-guide/)
