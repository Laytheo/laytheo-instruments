# OTS Notes

A skill for creating and editing single notes in a vault organized by the [Ontological Type System](https://laytheo.com/instruments/ontological-type-system) (OTS). The method is defended elsewhere; this skill executes it, one note at a time, with a duplicate check first and a body proportioned to what the user actually knows.

## Make it yours

This is a starting point, not an install. It is one person's working method, written for an AI agent, and it is meant to be adapted. Give `SKILL.md` to your own agent and ask it to fit the method to you. Have it interview you first, on two fronts: the technical setup (where your notes live, and what tools it has to read and write them) and the method itself (how you actually keep notes, what you want to remember, and which parts of this practice fit you and which do not). Then let it rewrite the skill around your answers.

`TAXONOMY.md` is the method reference (six closed root types, stub rules, templates, association discipline, body shape); have your agent work through it with you too. Once it is yours, say "make a note for X."

## What it assumes

- A markdown vault (Obsidian or similar) with YAML frontmatter and wikilinks.
- A note tool your agent can call, for example an MCP server over your vault: search, list, read, create, update.

## Files

- `SKILL.md`: the workflow for live note work.
- `TAXONOMY.md`: the method reference.
